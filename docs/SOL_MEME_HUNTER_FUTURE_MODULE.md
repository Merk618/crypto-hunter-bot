# SOL Meme Hunter Future Module

The SOL Meme Hunter is a future read-only module. It is not part of Crypto Hunter standalone v1.

## Scope

- Solana meme coins only
- Read-only discovery first
- Liquidity filters
- Rug-risk filters
- Social context filters
- Wallet concentration filters
- Age and volume sanity checks

## Not In Scope Yet

- Trading
- Paper trading
- Live execution
- Wallet signing
- Token swaps
- Automated buys or sells

## Validation First

The module should prove it can identify risky tokens, thin liquidity, suspicious holder concentration, and unstable social momentum before any execution system is discussed.
